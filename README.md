# Agricultural Performance Analysis

## Project Overview

This project analyzes agricultural performance data to identify patterns in crop yield, profitability, irrigation, seasonal performance, and environmental factors.

The analysis was performed using Python in Jupyter Notebook.

## Objectives

- Analyze crop-wise yield and profit
- Compare agricultural performance across seasons
- Compare performance across different states
- Study the impact of irrigation methods
- Analyze relationships between environmental factors and crop yield
- Identify important factors affecting agricultural performance

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Dataset

The dataset contains 4000 agricultural records with 28 features, including:

- State
- Crop
- Season
- Rainfall
- Soil Moisture
- Temperature
- Humidity
- Fertilizer
- Irrigation Method
- Yield
- Production
- Revenue
- Profit
- Water Usage
- Disease and Pest Risk

## Data Cleaning

Missing values were identified and handled using median imputation.

Duplicate records were also checked during preprocessing.

## Key Findings

- Kharif season showed the highest average profit.
- Sugarcane had the highest average yield and profit.
- Drip irrigation showed the highest average profit among irrigation methods.
- Punjab showed the highest average profit among the analyzed states.
- Water efficiency had a strong positive relationship with crop yield.
- Revenue showed a strong positive relationship with profit.
- Production showed a strong positive relationship with crop yield.

## Conclusion

The analysis indicates that crop type, season, irrigation method, and efficient water management play important roles in agricultural performance.

The insights from this analysis can help understand factors associated with higher crop yield and profitability.
